# JobScore Dashboard — Web

Dashboard React que muestra las ofertas de empleo puntuadas por el API, con filtros (score, ubicación, modalidad, prioridad) y gráficas del embudo de aplicación (enviada → respuesta → entrevista → oferta).

Ver el README de la raíz del repo para la visión general del pipeline completo.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS para estilos
- Recharts para gráficas (pendiente de instalar)

## Cómo ejecutarlo

```
npm install
npm run dev
```
